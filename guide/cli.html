CLI 与进阶 ​

官方参考：CLI Reference

两个主要可执行文件 ​

程序用途
wezterm（Windows 为 wezterm.exe）在终端中与 WezTerm 交互、脚本调用；需要时会委托 GUI
wezterm-gui（Windows 为 wezterm-gui.exe）从桌面环境启动 GUI

Windows 上若为桌面快捷方式 / 开始菜单启动，应优先指向 wezterm-gui.exe，以免系统再弹出一个用于日志的控制台窗口。

注意：在 Windows 上直接对 wezterm-gui.exe 运行 --help 可能看不到控制台输出（GUI 子系统）。请使用 wezterm.exe --help。

全局选项（节选） ​

text
wezterm [OPTIONS] [COMMAND]

  -n, --skip-config           跳过加载 wezterm.lua
      --config-file <PATH>    指定配置文件
      --config <name=value>   覆盖单项配置
  -h, --help
  -V, --version

启动并运行指定程序 ​

bash
wezterm start -- vim ~/.wezterm.lua
wezterm start --cwd /some/path

Windows PowerShell 示例：

powershell
wezterm start --cwd $HOME\projects

查看快捷键与字体 ​

bash
wezterm show-keys
wezterm show-keys --lua
wezterm ls-fonts
wezterm ls-fonts --list-system

wezterm cli 子命令 ​

在 WezTerm 窗格内运行时自动连接当前实例。以下子命令与 flag 已用 wezterm cli <子命令> --help（20240203-110809-5046fc22）核对，详见官方 wezterm cli。

子命令作用常用参数
list列出窗口 / 标签 / 窗格--format json
list-clients列出已连接客户端--format json
spawn新建标签（或窗口），输出新 pane-id--pane-id --domain-name --window-id --new-window --cwd --workspace，-- <命令>
split-pane分屏，输出新 pane-id--pane-id --left --right --top --bottom --horizontal --top-level --cells N --percent N --cwd --move-pane-id
activate-pane聚焦窗格--pane-id
activate-pane-direction聚焦相邻窗格Up / Down / Left / Right / Next / Prev，--pane-id
get-pane-direction查询相邻窗格 id方向，--pane-id
adjust-pane-size调整窗格大小方向，--amount N，--pane-id
zoom-pane缩放窗格--zoom / --unzoom / --toggle，--pane-id
kill-pane关闭窗格--pane-id
move-pane-to-new-tab把窗格移到新标签--pane-id --window-id --new-window --workspace
activate-tab切换标签--tab-id / --tab-index / --tab-relative / --no-wrap，--pane-id
send-text向窗格发送文本（默认按括号粘贴）--pane-id --no-paste，文本参数或 stdin
get-text输出窗格文本--pane-id --start-line --end-line --escapes
set-tab-title设置标签标题--tab-id / --pane-id，标题
set-window-title设置窗口标题--window-id / --pane-id，标题
rename-workspace重命名工作区--workspace / --pane-id，新名称
bash
# 在右侧分出 30% 宽的窗格运行 htop
wezterm cli split-pane --right --percent 30 -- htop
# 新窗格在下方、固定 10 行
wezterm cli split-pane --bottom --cells 10
wezterm cli activate-pane-direction Left
wezterm cli zoom-pane --toggle
wezterm cli get-text --start-line -50   # 最近 50 行（含回滚区）
wezterm cli list --format json

配置调试建议 ​

  1. 用 --config-file 指向一份最小复现配置，隔离问题。
  2. 用 --config key=value 临时验证单个选项。
  3. 需要排查按键时，可在配置中设置 debug_key_events = true（会在日志中打印按键），用完关闭。
lua
config.debug_key_events = true

与 multiplexer / 域相关的进阶主题 ​

WezTerm 支持本地与远程域、SSH 域、tls 域等高级用法。配色在 multiplexer 场景下可能由 服务端配置 决定。完整说明见官方文档中的 Multiplexing 章节（入口见 参考链接）。
